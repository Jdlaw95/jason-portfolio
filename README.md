# Jason Lawrence — Developer Portfolio

Personal portfolio site showcasing projects, skills, and work built across 
mobile, web, and AI automation.

**Live:** [portfolio.kaiblu.co.za](https://portfolio.kaiblu.co.za)

---

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel
- **Version Control:** GitHub

---

## Pages

| Page | Description |
|---|---|
| `/` | Homepage with hero and CTAs |
| `/projects` | Showcase of shipped projects |
| `/about` | Bio, tech stack, currently building |
| `/contact` | Email, GitHub, and studio links |

---

## Running Locally

```bash
git clone https://github.com/Jdlaw95/jason-portfolio.git
cd jason-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
