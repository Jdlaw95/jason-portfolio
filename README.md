# Jason's Developer Portfolio

Personal portfolio site built with Next.js 14, Tailwind CSS, and deployed on Vercel.

## Live Site
[portfolio.kaiblu.co.za](https://portfolio.kaiblu.co.za)

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Vercel (deployment)

## Running Locally
npm install
npm run dev
